# Sistema de Gestion Administrativa y Financiera

Base profesional para un sistema administrativo y financiero modular, multiempresa y preparado para evolucionar a SaaS.

## Estructura

- `frontend/`: React + Vite + TailwindCSS
- `backend/`: Node.js + Express + PostgreSQL
- `docs/`: guias paso a paso

## Inicio rapido

1. Lee [docs/SETUP.md](docs/SETUP.md)
2. Crea tu proyecto en Supabase
3. Ejecuta las migraciones SQL
4. Configura `.env` en `backend/` y `frontend/`
5. Instala dependencias y levanta ambos servicios
