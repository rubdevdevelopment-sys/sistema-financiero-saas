# Fitness ES-CO Localization

## Regla aplicada

Se mantuvo el codigo, las rutas tecnicas y la arquitectura en ingles, pero toda la UX visible de Fitness se localizo a espanol de Colombia.

## Se tradujo

- sidebar visual
- topbar visual
- titulos y subtitulos
- labels de tablas
- badges visibles
- estados de carga
- estados vacios
- mensajes de error visibles
- metricas y descripciones

## Se mantuvo sin traducir

- nombres de archivos
- hooks
- servicios API
- rutas tecnicas
- componentes internos

## Nota

La localizacion se aplico solo al workspace Fitness para no tocar EMAUS financiero ni alterar el resto del producto.
