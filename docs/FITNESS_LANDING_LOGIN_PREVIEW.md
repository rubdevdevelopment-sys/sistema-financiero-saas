# Fitness Landing Login Preview

## Objetivo

Mantener una landing/login visual de prueba para Fitness en:

- `/fitness/welcome`

con un rediseño mas premium, comercial y equilibrado.

## Estilo visual aplicado

- look SaaS fitness premium
- hero mas fuerte y vendible
- mockup visual tipo dashboard fitness
- metricas demo visibles
- card de acceso mejor integrada
- composicion responsive y mas limpia

La landing incluye:

- header con marca RubDev Fitness
- badge `Demo Fitness`
- CTA superior `Entrar a la demo`
- hero comercial con doble CTA
- metricas demo:
  - `54 ejercicios`
  - `8 rutinas`
  - `2 entrenadores`
  - `2 clientes`
- columna visual derecha con mockup fitness
- beneficios del modulo
- card visual de login demo
- credenciales demo visibles
- nota de preview sin autenticacion real
- footer simple

- sin conexion a auth

- sin llamadas API
