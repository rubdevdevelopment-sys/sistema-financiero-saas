# Fitness Gym Landing Preview

## Objetivo

Crear una landing/login preview enfocada en un gimnasio cliente, no en RubDev como administrador SaaS.

Ruta:

- `/fitness/gym-preview`

## Concepto visual

Empresa demo:

- `PowerFit Studio`
- `Centro de entrenamiento funcional`
- `Bogota, Colombia`

La experiencia se presenta como un portal propio para atletas y entrenadores del gimnasio.

## Contenido visible

La landing incluye:

- branding PowerFit Studio
- slogan comercial
- badge `Portal de atletas`
- hero principal con CTA de acceso
- CTA secundario para ver demo
- mockup visual del gimnasio
- card de login visual
- credenciales demo visibles
- bloque de estadisticas demo
- seccion `Que puedes hacer aqui`
- footer con firma del gimnasio

## Credenciales demo mostradas

- `trainer@rubdev.fit`
- `DemoFitness123!`

## Seguridad

- sin auth real
- sin llamadas API
- sin backend nuevo
- sin cambios de produccion
- sin impacto en EMAUS
- sin cambios financieros
- la landing `/fitness/welcome` sigue intacta
